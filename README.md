# Primer-Parcial-de-Arquitectura-de-Software
Simulador interactivo de CPU de 8 bits (arquitectura von Neumann / x86) y memoria principal de 256 bytes, desarrollado en Excel + VBA. Ejecuta el ciclo Fetch-Decode-Execute-Store paso a paso o en modo continuo, con registros, banderas y log de micro-operaciones. Parcial 1 – Arquitectura de Computadoras, UCB.
